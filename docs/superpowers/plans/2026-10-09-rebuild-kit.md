# Комплект документов для повторения WhalesTracker с нуля (08–11) — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use subagent-driven-development (recommended) or executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Создать `docs/08-ui-spec.md`, `docs/09-deployment.md`, `docs/10-e2e-acceptance.md`, `docs/11-glossary.md` и обновить `docs/README.md`, чтобы проект можно было повторить с нуля без чтения кода.

**Architecture:** Исследование выполняют 4 параллельных read-only субагента на `glm-5.3-flash`; сборка, сверка с 01–07 и коммиты — в главной сессии. Каждый документ — отдельный коммит.

**Tech Stack:** Markdown (русский), репозиторий как единственный источник; источники фактов — код (`файл:строка`) и https://whalestracker.netlify.app/.

**Spec:** `docs/superpowers/specs/2026-10-09-rebuild-kit-design.md`

## Global Constraints

- Ветка: `docs/rebuild-kit`; в `master` не коммитить.
- Принцип контракта: поведение и UI — обязательны; стек — рекомендательный блок, не смешивать с «как есть».
- Язык документов — русский; каждое утверждение о текущем поведении — с источником (`файл:строка` или сайт).
- Правило дублей: деталь уже в 01–07 — ссылка; новый контракт — полный текст. Существующие 01–07 не править (кроме README).
- Субагенты-исследователи: модель `glm-5.3-flash` (z.ai), read-only.
- Исчерпывающие перечни без «и т.д.»: тексты сообщений, env-переменные, поля форм, колонки таблиц.
- Известные баги помечать «известная проблема / воспроизводить не нужно» (перечень: конец 02-api.md, 06-docs-vs-code.md).

## Review Focus

1. Тексты UI-копирайтов и ошибок валидации, неполные или пересказанные «по смыслу» — 08 обязан содержать дословные строки из кода; проверка — grep строк по `client/`.
2. Пропущенные env-переменные (встречаются в `docker-compose*.yml`, `Dockerfile`, `nginx/`, коде) — проверка — grep `process.env` и переменных compose-файлов против таблицы 09.
3. curl-примеры, несовместимые с реальными схемами ответов — сверка каждого примера с 02-api.md; пометка «не верифицировано», если Docker не поднимался.
4. Терминологические расхождения глоссария с 03-domain-tracker.md (названия фильтров/редиректов) — сверка списков: количество и имена совпадают с 03.
5. Противоречия между новыми документами и 01–07 — финальная сверка в Task 6 по явному чек-листу.
