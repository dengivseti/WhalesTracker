## Executive summary

**WhalesTracker** — self-hosted TDS (Traffic Delivery System): принимает входящий трафик по ссылке `/{groupName}?q={keyword}`, прогоняет клик через фильтры потоков (устройство, гео, браузер, ОС, языки, чёрные списки IP/сигнатур и др.), перенаправляет одним из ~18 способов (HTTP/JS/meta/iframe-редиректы, показ HTML/текста/JSON, коды ошибок), пишет клик в статистику и принимает постбеки конверсий от партнёрских сетей.

- **Стек:** MERN — Express + Mongoose (MongoDB) + Redis (ioredis), React+CRA+Material-UI (TS), Docker Compose (5 сервисов) + nginx; Node cluster.
- **Объём:** бэкенд — 6 роут-файлов (25 эндпоинтов), 7 моделей, движок трекера из 4 модулей; фронтенд — 7 страниц, ~30 компонентов, 6 state-контекстов на useReducer.
- **Auth:** cookie-сессии (MongoStore); первый пользователь создаётся автоматически при первом логине на пустой БД; ролей нет.
- **Состояние и риски для рерайта:** зависимости 2020 г. (mongoose 5, redis 3, Node 12 в Docker); 4 мёртвых/битых эндпоинта; утечки объектов ошибок в ответах; Telegram-уведомления и captcha-protect заявлены в настройках, но не реализованы; счётчики кликов потока не инкрементируются; `Stream.filters` — бессхемный массив. Детали — в конце [02-api.md](02-api.md) и [06-docs-vs-code.md](06-docs-vs-code.md).
